# Copilot Instructions for Squeak Flutter Project

## Project Overview
Squeak is a professional pet care management application built with Flutter using Clean Architecture principles. This file contains specific instructions for GitHub Copilot to maintain code quality, consistency, and architectural patterns.

## Architecture & Design Patterns

### Clean Architecture Compliance
- Always follow the three-layer architecture: **Domain → Data → Presentation**
- Place business logic in the **Domain layer** (entities, use cases, repositories)
- Implement **Repository pattern** with abstract base classes
- Use **Data Sources** (Remote/Local) for external data access
- Keep UI logic in **Presentation layer** with BLoC/Cubit state management

### Folder Structure Standards
```
lib/
├── core/
│   ├── network/          # API clients, interceptors
│   ├── error/           # Error handling, failures
│   ├── utils/           # Helpers, constants, extensions
│   ├── service/         # Global services, locator
│   └── theme/           # UI theme, colors, typography
├── features/
│   └── feature_name/
│       ├── data/

│       │   ├── models/         # Data models with JSON serialization
│       │   └── repositories/   # Repository implementations
│       ├── domain/
│       │   ├── entities/       # Business objects (no dependencies)
│       │   ├── repositories/   # Abstract repository contracts
│       │   └── usecases/       # Business logic operations
│       └── presentation/
│           ├── cubit/          # State management
│           ├── pages/          # Screen widgets
│           └── widgets/        # Reusable UI components
```

## Code Standards & Conventions

### Naming Conventions
- **Files**: Use snake_case for all file names (`pet_screen.dart`, `login_cubit.dart`)
- **Classes**: Use PascalCase (`PetEntity`, `LoginCubit`, `PetRepository`)
- **Variables/Functions**: Use camelCase (`petList`, `getUserData()`)
- **Constants**: Use SCREAMING_SNAKE_CASE (`API_BASE_URL`, `MAX_RETRY_COUNT`)
- **Enums**: Use PascalCase with descriptive names (`AppointmentStatus`, `PetGender`)

### Entity Classes
```dart
class PetEntity extends Equatable {
  final String id;
  final String name;
  final String breedId;
  final DateTime birthDate;
  
  const PetEntity({
    required this.id,
    required this.name,
    required this.breedId,
    required this.birthDate,
  });
  
  @override
  List<Object?> get props => [id, name, breedId, birthDate];
}
```

### Use Case Pattern
```dart
class GetOwnerPetsUseCase extends BaseUseCase<List<PetEntity>, String> {
  final PetRepository repository;
  
  GetOwnerPetsUseCase(this.repository);
  
  @override
  Future<Either<Failure, List<PetEntity>>> call(String ownerId) async {
    return await repository.getOwnerPets(ownerId);
  }
}
```

### Cubit State Management
```dart
class PetCubit extends Cubit<PetState> {
  final GetOwnerPetsUseCase getOwnerPetsUseCase;
  
  PetCubit({required this.getOwnerPetsUseCase}) : super(PetInitial());
  
  static PetCubit get(BuildContext context) => BlocProvider.of(context);
  
  Future<void> getOwnerPets() async {
    emit(PetLoading());
    final result = await getOwnerPetsUseCase(ownerId);
    result.fold(
      (failure) => emit(PetError(failure.message)),
      (pets) => emit(PetLoaded(pets)),
    );
  }
}
```

## Error Handling & Networking

### Failure Classes
```dart
abstract class Failure extends Equatable {
  final String message;
  final int? statusCode;
  
  const Failure(this.message, [this.statusCode]);
  
  @override
  List<Object?> get props => [message, statusCode];
}

class ServerFailure extends Failure {
  const ServerFailure(super.message, [super.statusCode]);
}

class NetworkFailure extends Failure {
  const NetworkFailure(super.message);
}
```

### API Integration
```dart
class PetRemoteDataSource {
  final DioFinalHelper dioHelper;
  
  PetRemoteDataSource(this.dioHelper);
  
  Future<List<PetModel>> getOwnerPets(String ownerId) async {
    try {
      final response = await dioHelper.getData(
        method: EndPoints.ownerPets,
        language: true,
      );
      return (response.data as List)
          .map((json) => PetModel.fromJson(json))
          .toList();
    } on DioException catch (e) {
      throw ServerException(e.response?.data['message'] ?? 'Server error');
    }
  }
}
```

## Testing Standards

```dart
group('PetCubit', () {
  late PetCubit cubit;
  late MockGetOwnerPetsUseCase mockGetOwnerPetsUseCase;
  
  setUp(() {
    mockGetOwnerPetsUseCase = MockGetOwnerPetsUseCase();
    cubit = PetCubit(getOwnerPetsUseCase: mockGetOwnerPetsUseCase);
  });
  
  test('should emit [PetLoading, PetLoaded] when getOwnerPets is successful', () async {
    // Arrange
    when(() => mockGetOwnerPetsUseCase(any()))
        .thenAnswer((_) async => Right(tPetList));
    
    // Act
    cubit.getOwnerPets();
    
    // Assert
    expectLater(cubit.stream, emitsInOrder([
      PetLoading(),
      PetLoaded(tPetList),
    ]));
  });
});
```
